User & product guide

Tổng quan và quyền truy cập

SYNTRA FILES là ứng dụng quản lý tệp Android. README mô tả định hướng thao tác cảm ứng, lựa chọn thư mục và phạm vi quyền truy cập theo Android Storage Access Framework.

  • Người dùng cần cấp quyền cho vị trí lưu trữ được chọn.
  • Android có thể giới hạn một số thư mục hệ thống.
  • Không mặc định rằng ứng dụng có quyền truy cập toàn bộ thiết bị.

Build & contribution

Build APK và đóng góp

Repository mô tả quy trình build qua GitHub Actions. Đây là bản build phục vụ kiểm tra; không đồng nghĩa với APK phát hành chính thức.

  • Mở tab Actions và chọn Android CI.
  • Chọn Run workflow nếu workflow hỗ trợ thao tác thủ công.
  • Đọc hướng dẫn đóng góp trước khi gửi Issue hoặc mã nguồn.

SYNTRA OS

System architecture

Kiến trúc hệ điều hành

Tài liệu kiến trúc trình bày mô hình microkernel, các lớp hệ thống, mục tiêu kiến trúc CPU và chiến lược phát triển theo giai đoạn.

  • Bootloader, Microkernel, quản lý bộ nhớ và tiến trình.
  • IPC, driver, dịch vụ hệ thống và runtime ứng dụng.
  • ARM64 là mục tiêu ưu tiên ban đầu; x86_64 và RISC-V là các mục tiêu kiến trúc.

Testing / Android / Termux

Chạy SyntraOS trong QEMU

Hướng dẫn chạy kernel ARM64 trong QEMU trên Android/Termux. Quy trình này chạy máy ảo, không cài đặt hệ điều hành lên điện thoại và không thay thế Android.

  • Tải artifact từ lần chạy CI thành công gần nhất.
  • Khởi chạy QEMU ở chế độ console qua Termux.
  • ELF là kernel dành cho QEMU, không phải ảnh đĩa có thể flash.
