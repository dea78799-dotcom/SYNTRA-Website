SYNTRA PROJECT / PRODUCT OVERVIEW

SYNTRA
OS
An independent mobile OS project

SYNTRA OS là dự án nghiên cứu và phát triển hệ điều hành di động độc lập. Dự án hướng đến kiến trúc mô-đun, kernel tự phát triển và khả năng mở rộng trên nhiều kiến trúc phần cứng.

Version 0.1.0Early DevelopmentC / Rust / Assembly

Tổng quan dự án

Kernel

Định hướng xây dựng Custom Microkernel làm lõi của hệ điều hành.

Kiến trúc phần cứng

Mục tiêu hỗ trợ ARM64, x86_64 và RISC-V.

Nền tảng

Định hướng thiết bị di động và hệ sinh thái ứng dụng riêng.

Ngôn ngữ

C, Rust và Assembly là các ngôn ngữ chính được nêu trong dự án.

Các thành phần kiến trúc dự kiến

  • Bootloader và Microkernel
  • Memory Manager và Process Manager
  • IPC System và Hardware Drivers
  • System Services và Application Runtime
  • Syntra UI và Security System

Kiểm thử và phát triển

Repository hiện mô tả quy trình CI kiểm tra kernel ARM64 trong QEMU và cung cấp ELF dưới dạng workflow artifact. Có hướng dẫn chạy bản console trong môi trường Android/Termux.

Đây là dự án đang phát triển; chưa nên xem là hệ điều hành hoàn thiện hoặc sẵn sàng cài đặt trên thiết bị sử dụng hằng ngày.
