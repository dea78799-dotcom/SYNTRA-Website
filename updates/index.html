SYNTRA OS

Independent mobile OS · Custom microkernel

v0.1.0 · Current repository versionSYNTRA OS

Early development baseline

Phiên bản nền tảng được mô tả trong README của repository.

  • Định hướng hệ điều hành di động độc lập với Custom Microkernel.
  • Mục tiêu kiến trúc ARM64, x86_64 và RISC-V; ngôn ngữ chính C, Rust và Assembly.
  • README ghi nhận quy trình CI kiểm tra kernel ARM64 trong QEMU và xuất ELF thành workflow artifact.
  • Các thành phần kiến trúc được định hướng gồm bootloader, kernel, quản lý bộ nhớ, tiến trình, IPC, driver, dịch vụ hệ thống, runtime ứng dụng, giao diện và bảo mật.
Ghi chú: Các mục trên phản ánh nội dung README tại repository ở thời điểm cập nhật trang này. Đây không phải cam kết rằng mọi tính năng đều đã hoàn thiện hoặc đã được kiểm thử trên thiết bị thực tế. Phiên bản mới nhất và trạng thái build có thể thay đổi; hãy mở GitHub để xem nguồn chính thức.
