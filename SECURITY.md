# Security Policy

## Supported versions

Security fixes are applied to the current public website version on the `main` branch.

## Reporting a vulnerability

Please do not publish credentials, personal data, or a working exploit in a public issue.

Send a concise private report to **vanhuong05042025@gmail.com** with:
- The affected page or repository path.
- A brief description of the security impact.
- Safe reproduction notes that do not access other people's accounts or data.

Do not attempt denial-of-service testing, access other users' data, or modify content beyond what is necessary to demonstrate a suspected issue. The SYNTRA team will review the report and coordinate a fix before public disclosure.

For urgent account or credential exposure, revoke or rotate the affected credential first, then report the incident.
